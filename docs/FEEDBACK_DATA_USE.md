# 피드백과 데이터 이용 범위

v1 · 2026-10-25 · 유지보수자: [brucedata](https://github.com/brucedata)

Salesman은 현재 API 키 없이 사용하는 로컬 데모입니다. 앱에서 작성한 문의·초안·승인 기록은 사용자의 브라우저에 저장됩니다. 이 변경은 앱 사용 추적, 중앙 데이터베이스, 자동 업로드를 추가하지 않습니다. npm 설치나 글꼴·플랫폼 스크립트 같은 기존 외부 리소스 요청까지 없다는 뜻은 아닙니다. 기본 오류 수집도 비활성화되어 있습니다.

## 공개 피드백

[데모 사용 피드백](https://github.com/brucedata/salesman-hackathon/issues/new?template=demo-feedback.yml)은 GitHub의 공개 이슈입니다. GitHub 계정이 필요하며 계정명·본문·댓글·첨부는 다른 사람이 열람·복사할 수 있습니다. 실제 고객 대화·연락처·녹음·API 키·비공개 화면은 제출하지 마세요. 소프트웨어의 MIT 라이선스가 피드백 원문이나 고객 데이터의 판매 허락을 대신하지 않습니다.

기본 목적은 오류 재현, 문서와 사용 흐름 개선, 답변과 수정 이력의 공개입니다. 설치 실패도 환영합니다. 긍정적 후기·스타·구매·별도 이용 허락은 지원 조건이 아닙니다. 공개 이슈는 삭제나 수정 뒤에도 외부 복제본·알림·GitHub 기록에 남을 수 있습니다. GitHub 자체 처리는 [GitHub 개인정보 처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)을 따릅니다.

## 서로 독립적인 선택 항목

| 선택             | 목적과 항목                                                                                                          | 이용 기간                          |
| ---------------- | -------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| 신청 근거용 집계 | 업종·시도한 흐름·완료 여부·재사용 의향 네 항목의 익명 집계를 프로젝트 개선 보고와 Claude for Open Source 신청에 사용 | 제출일부터 12개월 이내의 집계 작업 |
| 공개 사례 인용   | 프로젝트 소개와 Claude for Open Source 신청에 공개 이슈 링크·GitHub 계정명·짧은 비밀 없는 의견 인용                  | 제출일부터 12개월 이내의 새 인용   |
| 상업 통계 이용   | 업종·시도한 흐름·완료 여부·재사용 의향 네 항목을 집계하여 무료·유료 리포트 제작                                      | 제출일부터 12개월 이내의 집계 작업 |

각 체크박스는 처음부터 선택되어 있지 않으며, 공란은 허락하지 않음입니다. 모두 거부해도 데모 사용과 피드백 처리는 동일합니다. 별도 목적, 추가 항목, 기간 연장에는 다시 허락을 요청합니다. 법률상 필요한 고지·권리 검토를 대체하는 포괄 동의나 개인정보 판매 허락이 아닙니다.

각 집계용 원자료 작업본에는 네 항목과 동의 확인용 최소 참조만 기록하며 접근을 제한합니다. 동의·기간·철회 확인용 참조는 통계 결과와 분리합니다. 자유서술·계정명·원본 링크·개별 응답 행은 통계 상품에 포함하지 않습니다. 작업본은 12개월 만료 또는 철회 확인 시 해당 선택 이용을 중단하고 삭제합니다. 이 정책이 GitHub 원본 이슈의 자동 삭제를 뜻하지는 않습니다.

표본이 작거나 여러 항목을 조합해 개인·사업자를 추정할 수 있으면 결과를 공개·판매하지 않습니다. 소수 셀을 합치거나 제외하고, 제외 결과를 다른 합계로 역산할 수 있는지도 검토합니다. 단순히 이름을 지우거나 일정 인원 수를 넘기는 것만으로 익명성이 확인되지는 않습니다. 실제 판매 전에는 항목·권리·식별 위험과 해당 운영 방식에 적용되는 의무를 검토해야 합니다.

이 데모의 성공률·재사용 의향은 자발적인 체험 응답입니다. 실제 매출, 전환율, 고객 응대 생산성 또는 업계 전체를 대표하는 통계로 표시하지 않습니다. 데모의 예시 점수와 유지보수자·AI 테스트는 외부 사용자의 실적으로 세지 않습니다.

## 수정·철회 요청

본인이 작성한 이슈에 `신청 근거용 집계 철회`, `공개 사례 인용 철회`, `상업 통계 이용 철회` 또는 `모든 선택 이용 철회`라고 댓글을 남겨 주세요. 새 개인정보를 적을 필요가 없습니다. 유지보수자는 새 인용·미배포 집계 전에 허락 상태를 확인하고 작업 기록을 갱신합니다. 이미 제출된 신청서·배포된 리포트·타인의 복제본을 모두 회수할 수 있다고 약속하지는 않습니다. 공개 본문에 민감정보를 잘못 올렸다면 값을 다시 적지 말고 [보안 제보 안내](../SECURITY.md)에 따라 비공개 경로를 요청하세요.

## 유지보수자를 위한 기준

[실적 기록 절차](ADOPTION_EVIDENCE.md)를 따릅니다. 공개 이슈라는 이유만으로 상업 통계에 넣지 말고, 선택 항목과 최신 댓글·기간을 직접 확인하세요. 작성된 원자료 CSV는 저장소에 커밋하지 않습니다. 현재 제공하는 CSV는 헤더뿐인 양식입니다.

이 범위는 초기 프로젝트 운영 설계입니다. 실제 통계 상품의 적법성·익명성을 인증한 문서가 아닙니다. 참고: [개인정보 보호법 제15조 제2항의 동의 고지 사항](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1029334809), [개인정보보호위원회 가명정보 안내와 검토 절차](https://pipc.go.kr/np/default/page.do?mCode=D040010000).
